# NextPhoto

[English](README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md)

[下载最新 APK](https://github.com/rayqwe1234/NextPhoto/releases/latest) · [版本记录](https://github.com/rayqwe1234/NextPhoto/releases)

以 Nextcloud 为照片来源的原生 Android 相册。支持繁体中文、简体中文与英文界面，采用大标题、日期分组、沉浸式网格，支持浅色／深色模式。无广告、无付费功能、无第三方分析追踪。

**目前版本：0.1.7，Release 正式签名版。** 主要适配目标为 Nextcloud 34.0.3、Android 16；最低 Android 10。实际服务器互通和实体手机背景备份仍须完成验收，请先使用测试照片。

这是独立开发的客户端，并非 Nextcloud 官方产品。不需要部署额外后端，也不会替你更改服务器设置。

本版由 Nextcloud Photo 更名为 NextPhoto，使用新的蓝底白色光圈图标。软件包识别及签名保持兼容，既有加密相册目录 `Nextcloud Photo Vault` 与导出位置 `Download/Nextcloud Photo` 延续使用。

## 语言

界面自动跟随系统的第一语言：繁体中文（含台湾、香港、澳门）、简体中文及英文。其他语言一律使用英文，即使系统的第二语言是中文。切换系统语言后重新打开 App 即可。文件名、相册名称与既有备份路径不会被翻译或改名；服务器传回的消息及先前保存的历史错误保留原文。

## 安装与登录

1. 安装交付的 `NextPhoto-v0.1.7.apk`。Android 如有提示，允许目前使用的文件管理器安装 App。沿用相同签名，可直接覆盖更新 0.1.0／0.1.1／0.1.2／0.1.3／0.1.4／0.1.5／0.1.6，保留账号与数据。
2. 输入 Nextcloud 的 **HTTPS** 网址，可以包含自定义端口或安装子路径，例如 `https://cloud.example.com:8443/nextcloud`。
3. 点选「连接我的 Nextcloud」，在浏览器完成登录与授权，再返回 App。App 不需要你的主密码。
4. 首次索引会逐步加载照片；可在设置指定云端扫描文件夹。Photos 不可用时仍可浏览文件照片库与文件夹，原因会显示于相册标签页。

不支持忽略凭据验证、自签凭据绕过或明文 HTTP。若服务器使用私有凭据，请先配置 Android 信任的凭据。

## 功能与操作

| 画面 | 操作 |
| --- | --- |
| 照片 | 按日分组、日期跳转、2–5 栏网格、文件名与相册名搜寻、视频／收藏／离线筛选 |
| 照片浏览 | 左右滑动、双指缩放、加载原图、视频播放、详细 EXIF 信息 |
| 多选 | 长按照片，加入 Photos 相册或加入离线下载 |
| 相册 | 创建、改名、加入／移除成员，与 Nextcloud Photos 互通；另有文件夹浏览 |
| 加密相册 | 真实加密照片、视频、文件名、相册名称及缩略图；密码／指纹解锁，退出清除解密工作阶段 |
| 更多操作 | 文件移动与改名、手机下载、系统分享、只读公开连结、密码与到期日、撤销连结 |
| 编辑 | 可拖曳裁剪框、四角与边缘缩放、三分线构图、−180° 至 +180° 连续旋转滑杆、镜像、亮度；以原解析度另存 JPEG 副本并上传，不覆盖原文件 |
| 传输 | 持久化上传／下载队列、进度、取消、错误提示与重试、清空历史记录 |
| 设置 | 账号容量、最后同步、扫描范围、自动备份、网络限制、外观、缓存与退出登录 |

拍摄日期优先采用服务器提供的元数据；没有数据时先用修改日期。读取 EXIF 时会补齐缺少的拍摄日期。首次索引不会为取得 EXIF 大量下载原图。

编辑时直接拖曳裁剪框内部可移动范围，拖曳四角或边缘可调整大小；框外区域会变暗。横向拖动旋转滑杆可连续调整角度，也可点选「归零」。裁剪依旋转后的照片座标输出，预览框选与另存结果一致；倾斜旋转产生的空白边缘可用裁剪框移除。「重设」恢复全部编辑设置。

「保存到手机下载文件夹」会导出到 `Download/Nextcloud Photo`；「离线保存」保存在 App 私有空间。导出的文件不会因退出登录而删除。清除离线副本只影响 App 本机数据。

传输页的「清空历史记录」会移除已完成、失败及已取消的列表记录，保留等待中与传输中的工作；不删除照片，并保留备份去重数据，避免再次上传已备份项目。没有可清除的记录时按钮停用。

## 加密相册

在「相册 → 加密相册」创建，支持从手机或云端导入加密副本，原文件保留。退出或进入背景立即锁定，解密照片与视频不写入磁盘；指纹入口在相册锁定页固定显示；首次使用需先用相册密码解锁，再按页面上方的「启用指纹解锁」。尚未登录指纹或装置不支持时会显示原因。支持每张 32 MiB 以内的图片及每部 32 GiB 以内的视频；视频分块加密上传、按需解密播放并支持进度拖曳，不使用明文磁盘缓存。加密传输需停留在前景，不支持背景续传。Nextcloud Photos 网页无法预览密文。请妥善保存相册密码及完整云端文件夹备份。

详见 [加密相册使用、格式与清除范围](docs/ENCRYPTED_ALBUMS.md)。

## 手动上传与自动备份

- 手动上传：照片页右上角「＋」，以 Android 系统选择器选取照片或视频。
- 自动备份默认关闭。在设置选择手机来源文件夹、保存云端上传目的地，再启用自动备份。备份文件按 `年/月` 整理。
- 使用系统文件夹授权，不要求读取整个手机相册。拒绝或取消授权时，不开始备份；撤回授权后会显示错误并要求重新选取。
- 默认仅使用 Wi-Fi 等不计量网络。Android 会自行安排背景执行时间，省电模式、强制停止 App 或厂商背景限制可能延后备份。可使用「立即扫描备份」触发扫描。
- 单向备份：手机删除不会删除云端文件。相同来源、大小、修改时间及目的地不重复调度；同名文件会产生带识别码的新名称。
- 大于 10 MiB 的文件使用 10 MiB 分块，最终组合禁止覆盖，支持重试时复用已上传分块。未完成的服务器暂存由 Nextcloud 的到期机制处理。
- App 先创建本机上传暂存，手机需有足够可用空间。上传成功经服务器确认后才标记完成；程序中断后若目的档已存在，会比对 SHA-256 以避免误判成功或重复上传。

## 删除与隐私

- 「从相册移除」只删除 Photos 相册成员关系，原始照片保留。
- 「删除云端原文件」需要确认；可否复原与保留期限依服务器回收站能力。删除与移动使用 ETag 条件，防止对已被他人更新的文件执行过时操作。
- 登录凭据由 Android Keystore 保护。系统备份与装置搬移排除 App 私有数据；网络请求不会将凭据传往其他网域。
- 缩略图缓存上限 1 GB，指定离线原文件另外计算。退出登录停止传输并清除登录凭据、索引及 App 私有副本。

## 已知边界

- 同时登录一个账号。使用 Photos 的个人相册界面；Memories、人物辨识、地图及智慧相册不在第一版范围。
- 格式支持取决于 Android 解码器与服务器预览设置。无法显示时可下载交给其他 App；没有内建视频转码、RAW 编辑或视频剪裁。
- 编辑输出 JPEG，不保留动态照片、HDR 或动画信息。超过 4000 万像素或超出装置可用内存的原图会提示使用外部编辑器，不静默缩小解析度。
- 服务器没有缩略图或权限不足时会显示状态，不会把其他账号的缓存拿来替代。
- 自动备份取决于 Android 调度，并非即时常驻同步；重新安装 App 后原本的备份历史不会保留。
- 完整测试记录与尚待验收项目见 [测试报告](docs/TESTING.md)。

## 从源代码构建

需要 JDK **21**（Android 16 Robolectric 测试需要）、Android SDK Platform 36、Build Tools 36.0.0。工程使用 Gradle 9.4.1、Android Gradle Plugin 9.2.0、Kotlin／Compose compiler 2.3.10，依赖版本固定于 Gradle 设置。

设置 `JAVA_HOME`、`ANDROID_HOME`，或在未追踪的 `local.properties` 设置 `sdk.dir`，然后执行：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。`assembleRelease` 会执行程式码与资源缩减；若没有发布密钥，输出为未签名 APK。

本机交付密钥位于未追踪的 `.signing/`，**请自行安全备份此目录，未来更新需使用相同密钥**。密钥不包含于源代码压缩档或 Git。自行构建时可创建 `.signing/signing.properties`，填入 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`。

## 源代码结构

- `account`：Login Flow v2 凭据保存。
- `network`：Nextcloud DAV／OCS 通讯、网址验证与串流 XML 解析。
- `data`：Room、Paging、增量照片索引与相册关系。
- `transfer`：WorkManager 备份与可恢复传输。
- `ui`：Compose 照片库、浏览器、编辑器、传输与设置。
